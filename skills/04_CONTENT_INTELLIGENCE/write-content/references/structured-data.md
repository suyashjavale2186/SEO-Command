## Field procedure
Use structured data only when the page genuinely qualifies and the markup accurately represents visible content. Validate syntax and required properties according to current Google documentation, but treat the markup as a representation layer rather than a ranking or AI-citation switch. Keep the visible page authoritative; never create hidden data solely to influence search appearance. [Evidence Tier: Tier 1 — Officially documented]

## Concrete case
A recipe page visibly contains ingredients, instructions, and preparation details, so the implementation mirrors those visible fields in valid structured data. A marketing page with no visible review content does not receive fabricated review markup merely to seek a rich result. [Evidence Tier: Tier 1 — Officially documented]

## Failure modes
Markup that describes content the page does not show; deprecated or inapplicable properties; adding schema because “competitors have it”; or claiming that valid markup guarantees a rich result, ranking lift, or AI citation. [Evidence Tier: Tier 1 — Officially documented]
