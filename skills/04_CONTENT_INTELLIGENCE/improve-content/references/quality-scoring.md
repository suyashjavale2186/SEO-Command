# Quality Scoring for Updates

Use this reference to evaluate a **published page that is being changed**, not to score a fresh draft. The key question is whether the proposed update repairs an evidence-backed weakness while preserving useful performance and business value already present. [Evidence Tier: Tier 3 — Industry observation]

## Baseline-aware review
Capture the page's current query footprint, important landing-page behavior, conversion role, and known successful sections before editing. Identify what must be protected. A page that earns visibility for a useful subtask can lose value when an editor removes that coverage during a broad rewrite. [Evidence Tier: Tier 2 — Strong empirical evidence]

Classify the defect: stale facts, changed user intent, missing first-party evidence, competitor improvement, poor task completion, technical delivery, or a changed offer. The editor should be able to point to the defect rather than saying “the page feels old.” [Evidence Tier: Tier 3 — Industry observation]

## Concrete example
A software comparison page still earns strong category impressions but its commercial click-through weakens after competitors publish current pricing context. The update verifies current prices, clarifies the buyer criteria, and preserves the page's useful category definitions. The editor does not rewrite the entire article merely to make it “fresh.” [Evidence Tier: Tier 3 — Industry observation]

## Regression checks
After publication, recheck the original query set and conversion role alongside the intended improvement. Watch for lost coverage, new factual errors, or weaker business outcomes. A single post-change movement is an observation, not causal proof. [Evidence Tier: Tier 2 — Strong empirical evidence]

## Failure modes
Avoid changing several unrelated elements at once, deleting low-traffic sections without understanding their role, refreshing dates without updating substance, or using rankings alone as the success criterion. [Evidence Tier: Tier 3 — Industry observation]

## Evidence boundary
A change in performance does not identify a private Google mechanism. Any undocumented causal explanation remains **Tier 4 — Hypothesis**. Recommendations follow the centralized governance contract. [Evidence Tier: Tier 1 — Officially documented]
