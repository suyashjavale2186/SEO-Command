# Content Types for Briefing

The `content-brief` version of content types answers **“What should this page be?”** before drafting begins. It translates SERP evidence and the audience's task into a page format and evidence plan. [Evidence Tier: Tier 3 — Industry observation]

## Format-selection procedure
Start with the user job. If the searcher needs to compare options, a comparison structure is usually more useful than a generic explainer; if the searcher needs to complete a task, a procedural structure should expose prerequisites, sequence, and verification; if the query asks for meaning, define the concept before branching into detail. These are observed content patterns, not Google mandates. [Evidence Tier: Tier 3 — Industry observation]

Inspect the live SERP and classify the dominant result shapes. Record whether successful pages are guides, product pages, calculators, lists, tables, videos, local results, or mixed formats. The brief should explain the observed pattern without demanding a copy of competitors' headings. [Evidence Tier: Tier 3 — Industry observation]

## Briefing checklist
- State the user task in plain language.
- Choose the page format that can complete that task.
- Define the evidence each major section will need.
- Mark where first-party experience or expert input can create information advantage.
- Identify conversion role and next-best action.
- Flag sections that should **not** be added because they do not serve the task. [Evidence Tier: Tier 3 — Industry observation]

## Concrete scenario
For “best payroll software for a 50-person company,” the brief chooses a comparison format because the query expresses a selection problem. It requires current pricing sources, integration facts, buyer criteria, and an expert explanation of implementation trade-offs. It does not automatically append an FAQ section just because competitors do. [Evidence Tier: Tier 3 — Industry observation]

## Failure modes
A briefing fails when format follows a keyword instead of a task, when word count becomes the organizing principle, when schema is selected before content eligibility is understood, or when competitor structure is copied without considering the business's distinct evidence. [Evidence Tier: Tier 3 — Industry observation]

## Evidence boundary
Format selection is an evidence-led editorial decision. Any claim about private Google ranking mechanics remains **Tier 4 — Hypothesis** unless documented. Recommendations use the centralized output contract. [Evidence Tier: Tier 1 — Officially documented]
