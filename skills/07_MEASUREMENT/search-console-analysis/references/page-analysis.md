# Search Console Page Analysis

This reference focuses on **search-performance evidence at URL level**: which pages earn impressions and clicks, for which queries, and how their search appearance changes over time. It is distinct from analytics landing-page analysis, which begins after the click. [Evidence Tier: Tier 1 — Officially documented]

## Page-analysis procedure
Choose the page and comparison window, then inspect queries, impressions, clicks, CTR, average position, country/device segmentation where relevant, and search appearance. Preserve the exact filters and dates so another analyst can reproduce the observation. [Evidence Tier: Tier 1 — Officially documented]

Look for query mix changes, emerging queries, disappearing queries, changes in click efficiency, and pages that have impressions without meaningful clicks. Then compare the page's visible content with the query tasks it appears to serve. Search Console tells you what was observed in Search; it does not by itself tell you why the change occurred. [Evidence Tier: Tier 1 — Officially documented]

## Concrete scenario
A documentation URL gains impressions for a new product term but clicks remain modest. The analyst inspects the new query cluster and finds that the page answers the setup task while searchers now expect pricing context. The recommendation is framed as a content/intent investigation, not as proof of a specific ranking-system change. [Evidence Tier: Tier 1 — Officially documented]

## Failure modes
Comparing mismatched windows, ignoring data aggregation, treating average position as an absolute rank, and moving directly from a Search Console signal to a causal claim. [Evidence Tier: Tier 1 — Officially documented]

## Evidence boundary
Search Console provides first-party search-performance evidence. Interpretations beyond those fields require additional evidence and must be labeled appropriately. [Evidence Tier: Tier 1 — Officially documented]
## Practical handoff for page analysis
The analyst should leave a compact handoff that identifies the exact artifact, the evidence owner, the user or business outcome at stake, and the next validation action. For **page analysis**, record the observable state before interpretation so that a second practitioner can reproduce the decision without relying on the author's memory. [Evidence Tier: Tier 3 — Industry observation]

Use a topic-specific stop condition: pause when the evidence source is stale, the artifact is not comparable to the benchmark, or the proposed action depends on an undocumented Google mechanism. When an action is approved, preserve the rationale and the uncertainty so a later measurement cycle can test whether the decision was useful. [Evidence Tier: Tier 1 — Officially documented]
