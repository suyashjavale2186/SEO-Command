# Query Format Matching

This reference asks **what answer form best satisfies the observed query**. It is part of broad SERP analysis, so it evaluates the query and result landscape before a specific snippet or rich-result tactic is chosen. [Evidence Tier: Tier 3 — Industry observation]

## Format-reading procedure
Inspect the current organic result shapes for the query: prose explanations, ordered procedures, tables, calculators, videos, product pages, listicles, local results, or mixed results. Record which format repeatedly appears among relevant results and what user task that format appears to serve. [Evidence Tier: Tier 3 — Industry observation]

Map query wording to the task: “how to” implies a procedure; “best” often implies evaluation; “vs” implies comparison; a definition query usually needs an immediate concept explanation. These are useful linguistic signals, not universal intent rules. [Evidence Tier: Tier 3 — Industry observation]

## Concrete scenario
For “how to compare payroll vendors,” the SERP contains comparison tables and buyer guides rather than pure definitions. A new page should therefore make comparison criteria explicit and give readers a path to evaluate alternatives; it should not merely define payroll software. [Evidence Tier: Tier 3 — Industry observation]

## Failure modes
Copying one competitor's page format, ignoring mixed-result SERPs, confusing a SERP feature with the organic page's entire content format, and using an arbitrary answer length as the definition of a good match. [Evidence Tier: Tier 3 — Industry observation]

## Evidence boundary
SERP format reveals observable search-result patterns. It does not prove a private Google preference. Any undocumented causal explanation is **Tier 4 — Hypothesis**. [Evidence Tier: Tier 1 — Officially documented]

## Format worksheet
For each query, capture the visible result types, the apparent task each type satisfies, the content form used by the strongest comparable results, and any obvious exceptions. Then make the page-format recommendation from the whole pattern rather than from one ranking URL. [Evidence Tier: Tier 3 — Industry observation]

When the SERP is mixed, identify the dominant user jobs instead of forcing one “intent.” A query can legitimately require an explanatory definition followed by a product-selection path, and the analyst should explain that sequence when the evidence supports it. [Evidence Tier: Tier 3 — Industry observation]
